## 这是什么

**运营简历精修工坊** 是一款专为运营岗位求职者打造的简历优化工具。输入你的原始简历，AI 自动帮你：

- 🔍 检测语法问题并修正
- 💪 强化运营专属动词
- 📊 将模糊描述转化为量化数据句
- ⭐ 用 STAR 法则扩展经历
- 🎯 ATS 关键词匹配评分
- 🔗 检测链路过短和同质化风险
- 🎤 自动生成面试模拟题
- 📄 一键导出专业排版的 PDF 简历

**无需联网，无需注册，完全免费。**

## 功能指南

### 1. 选择运营方向

在工具栏最左侧选择你的目标岗位方向：

| 方向 | 适合场景 |
|---|---|
| 👤 用户运营 | 用户增长、留存、分层、生命周期管理 |
| 🎪 活动运营 | 策划拉新/促活/转化活动、GMV 指标 |
| 📝 内容运营 | 公众号/短视频/图文内容、阅读量/互动率 |
| 💬 社群运营 | 微信群/企微私域、社群活跃度/转化 |
| 📱 新媒体运营 | 抖音/小红书/B站/知乎平台运营 |
| 📊 数据运营 | 数据报表/BI/用户行为分析 |

> 选择方向后，AI 会针对该领域调整动词推荐和关键词匹配。

### 2. 一键润色

点击 **🔮 一键润色** 按钮，AI 自动执行：

1. 语法纠错（错别字、语病）
2. 动词强化（"负责"→"主导"、"参与"→"推动"）
3. 自动防重复替换（不会出现"推动推动"等问题）

润色后自动切换到 **前后对比** 标签，可以直观看到改动。

### 3. 语法纠错

单独点击，仅检查拼写和语法错误。适用于已经写好、只需要过一遍的场景。

### 4. 动词强化

将简历中的弱动词替换为运营行业认可的强力动词：

| 弱动词 | → | 强化动词 |
|---|---|---|
| 负责 | → | 主导 / 统筹 |
| 参与 | → | 推动 / 驱动 |
| 做了 | → | 执行 / 落地 |
| 帮助 | → | 赋能 / 支撑 |

### 5. 量化魔法棒

运营简历最加分的就是**数据**。点击后弹出表单，填写 5 个字段：

```
原始描述: "负责社群运营，提升了用户活跃度"
          ↓
基数: 5000人       →  提升前基准
增量: +1500人      →  具体增量
百分比: +30%       →  增长比例
时间: 3个月内      →  时间维度
工具: 企微SCRM     →  使用的工具
          ↓
生成: "3个月内通过企微SCRM管理5000人社群，用户活跃度提升30%，新增活跃用户1500人"
```

点击"应用到简历"即可替换原文。

### 6. STAR 扩展器

将一句话经历扩展为 STAR 四段式结构：

| 环节 | 含义 | 示例 |
|---|---|---|
| **S**ituation | 情境 | 公司新业务线冷启动，面临用户增长瓶颈 |
| **T**ask | 任务 | 负责搭建用户增长体系，3 个月内实现 DAU 翻倍 |
| **A**ction | 行动 | 搭建 RFM 分层模型，针对不同层级制定差异化策略 |
| **R**esult | 结果 | DAU 从 3 万增长至 6.5 万，新用户注册转化率提升 22% |

支持 4 种运营情境：拉新获客、激活留存、转化付费、召回流失。

### 7. 残缺检测

一键分析简历的两大问题：

- **链路过短**：找到只有结论没有过程的句子（如"提升了转化率"），建议补充数据
- **同质化评分 (0-100)**：判断你的简历和通用模板的相似度，分数越高越容易被 HR 忽略

### 8. ATS 匹配

ATS（Applicant Tracking System）是很多公司使用的简历筛选系统。它可以：

- 检测你的简历是否包含目标岗位的关键词
- 给出匹配度评分
- 一键插入缺失的关键词

> 提示：在左侧编辑器上方可以粘贴 JD（职位描述），ATS 会根据 JD 进行精准匹配。

### 9. 面试模拟

基于你的简历内容，AI 自动生成 9 道面试题，分为 4 类：

- 📊 **数据追问**："你说粉丝增长了 25%，具体是怎么做到的？"
- 🧠 **方法论**："你的用户分层逻辑是什么？"
- 🎯 **情境题**："如果社群活跃度突然下降 50%，你会怎么做？"
- 🔍 **细节确认**："你提到使用企微 SCRM，具体用了哪些功能？"

### 10. 历史快照

每次润色操作前自动保存当前版本。点击 **历史** 查看最近 5 次快照，可随时回退。

### 11. 撤销

点击 **↺ 撤销** 回退到上一次自动保存的状态。

## PDF 导出

### 操作步骤

1. 点击工具栏 **📥 导出** 按钮
2. 左侧选择格式（推荐 **PDF 简历**）
3. 右侧实时预览排版效果
4. 确认无误后点击 **导出.pdf**
5. 在打印对话框中：目标打印机选 **「另存为 PDF」** → 边距选 **「默认」** → 保存

### 导出格式

| 格式 | 适用场景 |
|---|---|
| **PDF 简历** | 投递用，专业排版，含深蓝渐变横幅 + 板块分层 |
| Markdown | 可导入 Notion/Obsidian 等编辑器继续修改 |
| 纯文本 | 无格式纯文字，适合粘贴到招聘系统文本框 |
| HTML 富文本 | 保留排版样式，可粘贴到支持富文本的邮件 |

### PDF 排版说明

导出的 PDF 自动按板块组织：

```
┌──────────────────────────┐
│   深蓝→紫色渐变横幅      │
│   张三 · 手机 · 邮箱     │
├──────────────────────────┤
│ 📋 求职意向              │
│ 📋 工作经历              │
│   公司名    角色 · 时间  │
│   · 要点 1 (数字高亮)    │
│   · 要点 2               │
│ 🚀 项目经验              │
│   项目名    时间          │
│   · 要点                 │
│ 🎓 教育背景              │
│ 🛠️ 核心技能   [标签云]   │
│ 💡 自我评价              │
└──────────────────────────┘
```

> **提示**：简历中使用 `## 标题` 或自然中文标题（如"工作经历"）都可以被自动识别为板块。

### 导出前再润色

点击左侧 **🔄 重新润色** 按钮，可以在导出前再做一次语法纠错 + 动词强化，不关闭弹窗。

## 常见问题

### Q: 我的数据安全吗？

A: 完全安全。本应用采用**离线优先**架构，所有 AI 处理逻辑在本地执行。你的简历内容存储在浏览器 localStorage 中，不会上传到任何服务器。当前版本使用 Mock AI（规则引擎）响应，即使未来接入真实 LLM，也由你自行配置 API Key。

### Q: 支持哪些简历格式？

A: 编辑区支持：
- 直接打字/粘贴文本
- 上传 `.txt` 纯文本文件
- 上传 `.docx` Word 文档（自动提取文字）

### Q: 为什么我点击"一键润色"没反应？

A: 请确保编辑区中已有简历内容。当前版本使用 Mock AI 引擎，基于规则匹配需要简历中有对应的文本。

### Q: PDF 导出后排版不对怎么办？

A:
1. 确保简历中使用了标题标记（如 `## 工作经历`）或中文板块标题（如"工作经历"单独一行）
2. 导出时选择「PDF 简历」格式
3. 在打印对话框中选择「另存为 PDF」，边距选「默认」

### Q: 移动端如何看到润色结果？

A: 点击底部 Tab 栏（润色/对比/ATS 等），面板会从底部弹出。如果刚执行了润色操作，会自动弹出对应面板。

### Q: iOS 可以用吗？

A: 可以。在 Safari 中打开网页版，通过「添加到主屏幕」安装为 PWA。APK 格式仅支持 Android。
